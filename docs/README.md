# Fynix Suite Website

Marketing landing page for the [Fynix Suite](https://github.com/Boc86) of open source software.

Hosted at **[https://boc86.github.io/Fynix-Hub/](https://boc86.github.io/Fynix-Hub/)**

## Stack

- HTML5
- CSS3 (vanilla, no frameworks)
- JavaScript (vanilla, no frameworks)

## Deployment

GitHub Pages is configured to serve from the `/docs` folder of the `master` branch.

## Sections

1. Hero — fullscreen brand intro with animated background
2. Products — Fynix Player (Available), Fynix Hub (Private Beta), Fynix Nav (Planned)
3. Why Fynix — core principles (Fast, Privacy, Open Source)
4. Gallery — app screenshots with lightbox
5. Roadmap — animated project timeline
6. GitHub — live stats from the Fynix Player repo
7. Support — Ko-fi call to action
8. Disclaimer — legal notice
9. Footer — branding and links
